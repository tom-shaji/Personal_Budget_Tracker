# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-09-06

### Added
- Initial release of Personal Budget Tracker
- Add, delete, and clear transactions
- CSV-based persistent storage
- Summary panel with income, expenses, balance, and count
- Expenses-by-category pie chart using Matplotlib
- Input validation for amounts and dates
- Dark-themed Tkinter interface
